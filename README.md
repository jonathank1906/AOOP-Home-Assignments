# Guide: How to Use
Running the app:
Navigate to \HW3 Data Visualization and execute `dotnet run` in the terminal.

Add graphs by clicking on a preset query in the left panel. Remove graphs by clicking on the trash icon.

## Main Features 
- Utilized the global food waste dataset for the assignment.
- 3 types of charts (line, bar, pie).
- 6 preset queries.
- Undo/redo action of removing and adding graphs.
